## Introduction
* Before we start, I want to talk about what design patterns are?
    - Design patterns are reusable solution for a commonly occurring problem in software development, that solution had been passed through many software developers till it reached to us, so it's quality is verified.
    - Also, it's a shared vocabulary among developers, imagine trying to explain a problem solution, instead of explaining the solution in detail, you can simply say go to the X-design pattern, it solves your problem.

* Do Desing patterns have categories?
    * Actually yes. design patterns can be categorized to mainly three categories:
        1. Creational patterns: Focus on object creation and the process of instantiating objects.



        2. Structural patterns: Focus on how classes and objects are composed to form larger structures.



        3. Behavioral patterns: Focus on interactions between objects and the distribution of responsibilities.
